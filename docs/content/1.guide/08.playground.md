The [playground](/playground) runs the library in this page. Encode, decode, identify and list, with the same executors the MCP server runs.

Pick a tool, pick an encoding, type. The answer shows up a moment after you stop. Underneath it you get the CLI line and the JSON a model would send for the same call, both ready to copy.

## Every state is a link

The address bar follows the form. `?op=identify&text=MZXW6===` opens straight on that question. Share it, bookmark it, paste it into an issue.

## Nothing leaves the tab

No server reads what you type. Paste the mystery string from the ARG you're stuck on. It stays with you.
