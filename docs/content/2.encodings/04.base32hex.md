---
title: Base32hex
description: RFC 4648 base32 with the extended hex alphabet. Sorts in the same order as the bytes
---

::encoding-facts{name="base32hex"}
::

Base32 with `0` to `9` and `A` to `V`. Why bother? Order. Sort the encoded strings and they line up exactly like the bytes. Plain base32 can't do that.

```ts
encode("base32hex", "foobar");  // "CPNMUOJ1E8======"
```

DNSSEC uses it for NSEC3 hashed owner names, unpadded. This codec writes the padded uppercase form from RFC 4648. It reads both.
