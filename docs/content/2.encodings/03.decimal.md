---
title: Decimal
description: Every byte as a plain number from 0 to 255. The ASCII table you already know. Spaced by default
---

::encoding-facts{name="decimal"}
::

The ASCII table, written out. `72` is `H`, `105` is `i`. You've seen it a hundred times.

```ts
encode("decimal", "Hi");                       // "72 105"
encode("decimal", "Hi", { separate: false });  // "072105"
```

Spaces or commas between numbers, both read the same. Without any separator, decimal can't tell `1 2` from `12`. So `separate: false` pads every byte to three digits, and decoding reads a run three at a time. Four digits in a row? That's an error, not a guess.

Anything over `255` doesn't fit a byte, and you get the index of it.
