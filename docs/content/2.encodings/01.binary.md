---
title: Binary
description: Eight bits per byte spelled out in zeros and ones. Spaces between bytes by default
---

::encoding-facts{name="binary"}
::

The most honest encoding there is. Every bit, out loud, most significant first.

```ts
encode("binary", "Hi");                       // "01001000 01101001"
encode("binary", "Hi", { separate: false });  // "0100100001101001"
```

Decoding skips whitespace, so both forms read back the same. A count that isn't a multiple of eight is an error, not a guess about where the missing bits went. Puzzles love this one. Ever counted zeros by hand at 2am? Don't.
