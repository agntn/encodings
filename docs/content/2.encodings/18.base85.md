---
title: Base85
description: Base 85 with the RFC 1924 alphabet in four byte groups. What Python b85encode and Mercurial write
---

::encoding-facts{name="base85"}
::

RFC 1924 came out on 1 April 1996. It wanted every IPv6 address as one 128-bit number in base 85. Notice the date? Nobody writes IPv6 that way. The alphabet stuck anyway.

```ts
encode("base85", "hello world");  // "Xk~0{Zy<MXa%^M"
```

This is the form people actually meet: four bytes as five characters, like [Ascii85](/encodings/ascii85), with a short last group cut. Python's `b85encode` writes it, and so does Mercurial. Git binary patches use the same alphabet and groups, with a length character in front of every line.

Not like Ascii85: no `z` for zeros, no `<~ ~>`, and whitespace is an error. Python doesn't skip it either. Ask for `base85` and you get this one. `a85` still means Ascii85.
