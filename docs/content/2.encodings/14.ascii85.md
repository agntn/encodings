---
title: Ascii85
description: Four bytes as five characters from ! to u with z for four zero bytes. PostScript and PDF
---

::encoding-facts{name="ascii85"}
::

Adobe's base85 from PostScript and PDF. Four bytes become one 32-bit number. That number goes out as five digits from `!` to `u`.

```ts
encode("ascii85", "Hello, World!");                         // "87cURD_*#4DfTZ)+T"
encode("ascii85", "Hello, World!", { delimiters: true });   // "<~87cURD_*#4DfTZ)+T~>"
encode("ascii85", new Uint8Array(4));                       // "z"
```

Four zero bytes are a single `z`, a small gift for sparse data. Decoding takes the `<~` `~>` wrapper or not, and skips whitespace. A `z` in the middle of a group is an error. Can five digits overflow 32 bits? `uuuuu` can, and it's refused.
