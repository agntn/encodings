---
title: Base58 (Flickr)
description: Base58 with the lowercase run before the uppercase one. Flickr short URLs
---

::encoding-facts{name="base58-flickr"}
::

Same 58 characters as Bitcoin's, different order. Flickr put lowercase before uppercase for its `flic.kr` short links, and that one swap makes every string look different.

```ts
encode("base58", "hello world");         // "StV1DL6CwTryKyV"
encode("base58-flickr", "hello world");  // "rTu1dk6cWsRYjYu"
```

Notice the cases flipped and the digits stayed? That's the whole difference. Decode a Flickr string with the Bitcoin alphabet and you get valid, wrong bytes. `identify` can't tell them apart either, both decode. Know your source.
