title: basE91

::encoding-facts{name="base91"}
::

The squeeziest one here. 91 printable ASCII characters, every one except `-`, `\` and `'`, and a variable 13 or 14 bits per pair. About 23% overhead, against 33% for base64.

```ts
encode("base91", "Hello, World!");  // ">OwJh>}AQ;r@@Y?F"
```

There's no RFC. Joachim Henke's reference C code is the spec, and this follows it bit for bit. One difference. The reference skips characters outside the alphabet, this decoder throws. Why? Silently skipping input is how you lose a byte and never notice.
