---
title: Quoted-Printable
description: RFC 2045 Quoted-Printable. Printable ASCII stays and the rest becomes =XX with soft breaks past 76 characters
---

::encoding-facts{name="quoted-printable"}
::

The MIME encoding for text that's mostly ASCII. Readable stays readable, everything else becomes `=XX`.

```ts
encode("quoted-printable", "café = ok ");  // "caf=C3=A9 =3D ok=20"
```

The `=` itself gets escaped, because it's the escape character. The trailing space becomes `=20`, because mail servers like to strip trailing spaces. Lines past 76 characters break with a soft `=` that decoding removes.

Line breaks in your input stay line breaks. Great for an email body. Random bytes, though? It runs past 100% overhead. Use base64 there.
