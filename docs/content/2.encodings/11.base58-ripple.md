---
title: Base58 (Ripple)
description: Base58 with the XRP Ledger alphabet where account addresses start with r
---

::encoding-facts{name="base58-ripple"}
::

The XRP Ledger shuffled the alphabet so that `r` is the zero digit. Version byte zero, address starts with `r`. Cute.

```ts
hex.encode(decode("base58-ripple", "rHb9CJAWyB4rj91VRWn96DkukG4bwdtyTh").bytes);
// "00b5f762798a53d543a014caf8b297cff8f2f937e8bf32ba9f"
```

That's the ledger's genesis account. Version `0x00`, then a 20-byte account ID, then `bf32ba9f`. Those last four bytes? The double SHA-256 of everything before them. Same checksum scheme as Bitcoin. This codec decodes the alphabet and leaves the checksum to you. So a typo here decodes without complaint.
