title: Base256
description: One symbol per byte. The multiformats base256emoji table by default or any table of 2 to 256 symbols you give it

::encoding-facts{name="base256"}
::

One byte, one emoji. That's the whole trick. The `emoji` alphabet is the base256emoji table from multiformats, and it's the default.

```ts
encode("base256", "gsmg", { multibase: true });  // "🚀😝🌈🌷😝"
decode("base256", "🚀😝🌈🌷😝", { multibase: true }).bytes;  // "gsmg" as bytes
```

## The rocket

Multibase puts 🚀 in front of base256emoji text. Fair enough. But 🚀 is also the table's first emoji, so it means byte 0 too. Read that string without `multibase` and you get a zero byte before `gsmg`. Nothing here strips it on a hunch, because a real zero byte looks exactly the same. `identify` tries both readings and puts the prefixed one first, since only that one reads as text.

Decoding skips whitespace and the emoji presentation selector. Copy `☄️` from a web page and it reads as the `☄` in the table.

## Your own table

Puzzles keep inventing alphabets. Card suits, runes, a grid of emoji in a picture. `symbols` takes the table in order, digit 0 first, and spaces between symbols don't count.

```ts
decode("base256", "♣ ♠ ♦", { symbols: "♠ ♥ ♦ ♣" }).bytes;  // [3, 0, 2]
encode("base256", new Uint8Array([3, 0]), { symbols: "♠♥♦♣" });  // "♣♠"
```

Fewer than 256 symbols? Then you get digits, not bytes. Four suits read 0 to 3, and turning those digits into a message is the next layer of the puzzle. A byte past the end of the table throws on encode.

A symbol is what you see. A flag, a family emoji joined with ZWJ, a suit with or without its selector, each is one symbol. Zero-width characters are the exception, each one is a symbol of its own, so text that looks empty can still hold a table.

## Order from a sample

Sometimes the puzzle never lists the alphabet. It just shows it, and the order things first appear in is the order. `sample` reads the table that way, so repeats are fine there.

```ts
decode("base256", "ᚦᚠᚢ", { sample: "ᚠᚢᚠ ᚦᚢ" }).bytes;  // [2, 0, 1]
```

Pass the ciphertext itself as the sample and every symbol gets numbered by its first sighting. Pass `symbols` or `sample`, not both.
