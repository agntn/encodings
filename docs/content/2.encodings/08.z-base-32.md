::encoding-facts{name="z-base-32"}
::

Zooko O'Whielacronx reordered the base32 alphabet in 2002. The characters that show up most are the easiest to read, write and say. Lowercase only, no padding. Ever read a key out loud over a call? That's who this is for.

```ts
zbase32.encode(new Uint8Array([0xf0, 0xbf, 0xc7]));  // "6n9hq"
encode("z-base-32", "hello");                        // "pb1sa5dx"
```

`6n9hq` is the example from the original paper. Zooko wrote it for Mnet. These days you meet it in Lightning, where node message signatures come out as z-base-32.
