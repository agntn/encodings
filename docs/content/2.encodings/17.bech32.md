---
title: Bech32
description: BIP173 bech32 with a prefix and 5-bit words and a BCH checksum. SegWit v0 and Lightning and Nostr
---

::encoding-facts{name="bech32"}
::

A human-readable prefix, a `1`, then 5-bit words and six characters of checksum. The checksum is a BCH code that catches any four wrong characters. Base58 never came close.

```ts
encode("bech32", "gm", { prefix: "test" });  // "test1vaks69jerm"
decode("bech32", "bc1qw508d6qejxtdg4y5r3zarvary0c5xw7kv8f3t4");
// bytes: the 20-byte program, details: { prefix: "bc", witnessVersion: 0 }
```

A valid segwit v0 address comes back as its witness program. Anything else comes back as the bytes its words carry. A Nostr `npub`, say, or a Cosmos account. Mixed case is an error. Over 90 characters too, unless you raise `limit`. Lightning invoice? Raise it.
